Q

Вопросы по выпуску

Рекомендуемый маршрут: 3–5 общих вопросов → 2–4 по расе → 1 ситуационное уточнение. Это выборка, а не обязательный минимум. Не заваливайте вопросами: пробелы в сложных правилах объясните игроку.

Общие вопросы — для всех рас
Ответ для инструктора

Изначально доступны /me (20 м), /mes (40 м) и /mew (2 м). Они описывают действия и видимые состояния. /do изначально не разрешена.

Ответ для инструктора

Нельзя сообщать мысли, желания, планы или использовать /me как обычную речь. Верно: «/me достал аптечку». Неверно: «/me хочет в больницу». Нельзя спамить одинаковыми отыгровками.

Ответ для инструктора

Для опознания нужно минимум три допустимых признака из таблицы «Маскировка». Обычный голос не считается признаком; акцент или характерный дефект речи может учитываться.

Ответ для инструктора

Предупредительный выстрел делается в воздух; уведомление видно в радиусе 150 м около 30 секунд. Видящий стрелявшего может ответить сразу, убегающего можно атаковать после уведомления, а остановившегося для RP сразу атаковать нельзя.

Ответ для инструктора

Обыск обязательно сопровождается /me (или автоматической /me). У жертвы две минуты для сообщения о спрятанных вещах. Если предмет спрятан, каждый элемент одежды проверяется отдельно с ожиданием 20 секунд.

Ответ для инструктора

Оставить еду и воду. Если забрали последнее оружие жертвы, нужно оставить другое. Когда оружия не было изначально, давать свое не требуется.

Ответ для инструктора

Тазер используется однократно по каждой цели, станлок повторными разрядами запрещен. По альфа-особям, ивентовым монстрам и гориллам стрелять нельзя.

Ответ для инструктора

После игромеханического нока у человека обязательный PainRP длится 30 минут. Бег, прыжки, драка и стрельба причиняют боль, а заполненное HP не отменяет травмы. Тяжелые ранения могут требовать более долгого лечения.

Ответ для инструктора

В обычном ноке персонаж без сознания: говорить и помнить происходящее до подъема он не может. После подъема учитывает боль и последствия травм.

Ответ для инструктора

Нет. Трансляция такого общения запрещена, а публикация материалов возможна только после предварительного согласования с администрацией.

Ответ для инструктора

Сообщить в #disconnect и вернуться в активную RP-ситуацию в течение десяти минут. Сцена не переигрывается: ее продолжают по обстоятельствам без выхода из роли.

Ответ для инструктора

Никакие знания, имущество и отношения прежнего персонажа переносить нельзя. Это спидран. У нового персонажа своя история, навыки и социальные связи, которые формируются в RP.

Ответ для инструктора

Нет. Нельзя оставлять человека в стяжках или мешке после завершения RP. Если связана группа, хотя бы одного человека оставляют свободным и с колюще-режущим предметом поблизости, чтобы он помог остальным.

Ответ для инструктора

В течение 30 минут после крайнего или боя инициатор не должен резко менять образ, выходить из игры, обращаться в альфа-форму или прятаться на базе/хабе. Для отдельных ситуаций есть исключения; при карманной краже без ограбления срок 15 минут.

Ответ для инструктора

Военная база Форт Занкудо и авианосец. Это закрытые территории организации L.I.E.S.

Ответ для инструктора

Нужно отыграть 10 минут бессознательного состояния и обязательно описать через /me потерю и возвращение сознания. Полный PainRP после механического нока в таком случае не назначается, но минимальные последствия удара отыграть необходимо.

Вопросы животным
Ответ для инструктора

Фразы максимум из двух-трех слов, пауза между фразами не менее пяти секунд. Слова длиннее четырех-пяти слогов нужно разделять на части. Из-за строения пасти идеальная человеческая речь невозможна.

Ответ для инструктора

Дни 1–3: человеческая речь непонятна; 4–7: понимание базовых потребностей; с 8-го дня: дальнейшее понимание и изучение произношения по 1 слову в день, для стайных Животных — по 2.

Ответ для инструктора

Нет. Отношение определяется опытом и происхождением. «Бывший питомец» может идти на контакт с первого дня; «Рядом с человеком» начинает с четвертого дня развития, но сохраняет осторожность при первых встречах. Бонус действует, если происхождение прописано в квенте.

Ответ для инструктора

Нет. Животное может находиться в группе, участвующей в конфликте, но само не вступает в бой против альфа-особи и не имеет права механически ее атаковать.

Ответ для инструктора

Примерно до уровня девятилетнего ребенка, максимум достигается не ранее месяца игры. На /ani можно использовать метафоры, образы и стихи.

Ответ для инструктора

Нет. Незнакомые вещи и их назначение изучаются через RP; обучение и взаимодействия с предметами отыгрываются через /me.

Ответ для инструктора

Животное может защищаться от вооруженного человека с соблюдением RP и правил боя. Рык желателен, но необязателен. Альфа-особей механически атаковать нельзя; коровы, феньки, еноты, панды и коты механически не атакуют. После сдачи нападение не возобновляют.

Ответ для инструктора

Слушать уже настроенную рацию можно. Самостоятельно говорить по ней, менять или сбивать частоту нельзя.

Ответ для инструктора

Общедоступные ящики-пропы можно. Аирдропы и ящики аномальных зон запрещены; выборочное изъятие одних специальных ресурсов без обучения тоже запрещено.

Ответ для инструктора

Нет. Животное не способно самостоятельно вырваться из захвата альфы или ивентового монстра.

Вопросы приматам
Ответ для инструктора

На родном языке /ani — свободно и грамотно. Человеческий язык изначально не освоен; его слова, чтение и счет нужно изучать в RP. Современные человеческие мемы и сленг для /ani не подходят.

Ответ для инструктора

Дни 1–3: 2 слова/день; 4–7: 4; 8–11: 8. С 12-го дня — до 10 самостоятельно по записям и на слух, сложные значения изучаются отдельно.

Ответ для инструктора

Первые контакты требуют осторожности, а реакция зависит от Происхождения. Привыкший к людям персонаж не обязан доверять каждому незнакомцу. «Бывший питомец» может вступать в контакт с людьми с первого дня.

Ответ для инструктора

В одиночку с начала игры давать отпор может только горилла. Другим нужна допустимая поддержка и оружие. Через 4 недели одиночный бой доступен всем, кроме капуцинов.

Ответ для инструктора

Сдаться или отступить; нельзя продолжать нападение, когда условия на поддержку больше не выполняются.

Ответ для инструктора

Приблизительно до уровня пятнадцатилетнего подростка, не выше. Даже развитый Примат не становится автоматически экспертом в науках, технике и устройстве человеческого общества.

Ответ для инструктора

Нет. Персонаж должен узнать назначение и освоить вещь через RP, соблюдая сроки развития и видовые ограничения. Функциональная возможность игрока не заменяет знания персонажа.

Ответ для инструктора

Нет. По общим правилам необходимо минимум три признака. Для Приматов люди внешне почти неразличимы; обычное звучание голоса не считается достаточным признаком.

Ответ для инструктора

Перенос зависит от вида и скорости по таблице «Кто кого может перенести». Карабкаться Приматы могут, но с переносимым персонажем нужно учитывать опасность срыва анимации и RP-логику. Само по себе карабканье с пассажиром не запрещено.

Ответ для инструктора

Нет. И Примат, и Животное проходят отдельное трехдневное обучение с RP-публикациями и подтверждением Кураторов. Допустимость зависит от вида, размера и ограничений на перенос.

Памятка инструктору — рабочие рекомендации
  • Перед телепортом в Авенджер необходимо обязательно уйти подальше от игроков, чтобы вас никто рядом не видел.
  • Запрещено разглашать/транслировать/передавать/показывать любую информацию, полученную в ходе своей работы.
  • Инструктору разрешено выпуститься на новом персонаже, только после одобрение внешности другим инструктором
  • Запрещено использовать рабочий админский функционал в своих целях.
  • Общение происходит на Вы и уважительно.
  • Ведем себя приемлемо, достойно и не нарушаем правила сервера.
  • Не игнорируем игроков, а участвуем в помощи и консультации по вопросам.
  • Запрещено изменять свои барбершоп данные с помощью маркера или барбер данных.
  • Запрещено выдавать админские предметы для выпуска игрокам которые не выходят или пользоваться ими в РП.
  • Ответственно и серьезно подходить к собеседованию игроков.
  • Вы не разбираете жалобы, а если вам пишут то вы отправляете их к @Мл.Ассистент или @Ассистент
  • Не выходить из авенджера с админскими вещами.
  • При собеседовании игроков Вы должны быть одеты в какой-то ХЭШ с символикой L.I.E.S.
  • В случае если игрок неадекватно ведёт себя в авенджере, делаете предупреждение и сообщаете Администрации.
  • Когда вы работаете - находитесь в голосовом канале Авенджер
  • Если у игрока при сворачивании игры не слышно разговоры в игре (Настройки → аудио → потеря фокуса → выкл)
  • Если у человека совсем маленький голос то зовем Администраторов или Ассистентов
  • Все действия с игроком, а именно: обнуление, накидывание нулевки, выпуск игрок - должны быть записаны в канал #admin-log

Барбер-данные: получить в ЛС, внимательно сверить ID и установить через «Младшим ассистентам». После установки — фото «накинул нулевку ID» в #avenger, данные в ветке и запись «~ накинул барбершоп ID» в #admin-log. Игра на человеческих хэшах запрещена — отправить установить нулевку.

Порядок выпуска для всех рас

  1. Проверить внешность. Отойти от остальных, включить шепот P → 1; для новичка провести собеседование и самостоятельно заполнить форму.
  2. Выдать единый стартовый набор и браслет-пропуск; изъять вещи по расе. Выдать расовую роль.
  3. После использования браслета сделать фото: «Важный → Позы стоя», животному — сидячая поза с видимой мордой. Без очков и маски. Подпись в #avenger-faces: «Имя Фамилия | ID»; натуральный цвет окрашенных волос — после ID в скобках.
  4. На маркере установить имя, фамилию и возраст по заявке и таблице ID–NAME. При необходимости 18+ — звездочка перед именем. Проверить отображение имени сообщением /me.
  5. Приглашение в #whitelist: 30 минут, 1 использование. Проверить ник Discord с ID. При необходимости снять CoolDown через .cdr и запросить 18+ у Ассистентов.
  6. Сохранить одежду в рюкзак. Avenger — последняя NON-RP зона. F11 — бинды и анимации, ПКМ — предпросмотр. ESC — бумажная карта; у животных карты нет, приматам нужно добыть ее через RP.
  7. Объяснить каналы: #whitelist — новости, #information — справка, #call-admin — помощь администрации, #wait-me — поиск RP-сессий.
  8. Людям перед прыжком: раскрыть парашют ЛКМ или F, клавиши не комбинировать; без анимаций и посадки на территории группировок, перед посадкой SHIFT. При ноке — тикет; если ситуацию увидели игроки, дальнейший исход зависит от RP, вплоть до RPK.
  9. После прыжка записать в #admin-log «~ выпустил ID», добавить «ft @тег» только реально помогавших сотрудников; для животных и приматов упомянуть Куратора расы.

Человек — что сделать

  • Собеседование: отойти в сторону, войс на шёпот (P → 1). Для первого персонажа инструктор сам заполняет форму; ссылку игроку не отправлять. Для следующего персонажа повторное собеседование по форме не требуется.
  • Фото: поза «Важный», без очков/масок; пост в #Avenger-faces: «Имя Фамилия | ID».
  • Паспорт: имя, фамилия, возраст; при 18+ - * перед именем; после смены ника — написать что-то в /me.
  • Discord: #whitelist (30 мин, 1 использование), объяснить Information, Call‑admin, Wait‑me.
  • Инструктаж: сохранить комплект в рюкзак; Авенджер — последняя NON‑RP зона; парашют ЛКМ или F (не комбинировать); без анимаций; не на территории группировок; перед приземлением - SHIFT; в ноке - тикет.
  • F11 — таблица биндов/анимаций; у человека есть бумажная карта (ESC).

Животные/обезьяны — что сделать

  • Фото: сидячая/уместная поза, без очков/масок; пост в #Avenger-faces: «Имя | ID».
  • Паспорт: фамилия «???» или 3 пробела (по правилам проекта).
  • Роли: выдать нужную — animal / capuchin / ape / orangutang / gorilla.
  • Карта: у животных карты нет; обезьянам — получить РП‑путём.
  • Сухпаек и вода — подножный корм. У животных забрать нож и топор, у приматов — топор; нахождение ножа примат отыгрывает через /me.

У животных забираем:

  • Топор и нож
  • Спальник
  • Набор для розжига костра
  • Аптечка
  • Сигнальный пистолет
  • Фильтр для воды

У обезьян забираем:

  • Топор
  • Спальник
  • Набор для розжига костра
  • Аптечка
  • Сигнальный пистолет
  • Фильтр для воды
Нож — РП‑добыча после выпуска.
