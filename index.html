Head Blend - проверка по правилам

🛈 Пояснение к барбер‑данным (раскрыть)

Правила:
shapeFirstId / shapeSecondId / shapeThirdId — не 0 и не 44, не повторяются;
shapeMix — 20–80; thirdMix — 15–75; в вкладке headBlend/skin нулей быть не должно.

Что что означает:

  • shapeFirstId - лицо первого родителя
  • shapeSecondId - лицо второго родителя
  • shapeThirdId - форма лица предка
  • shapeMix - микс лица родителей
  • thirdMix - микс лица предков
  • skinFirstId - цвет кожи первого родителя
  • skinSecondId - цвет кожи второго родителя
  • skinThirdId - цвет кожи предка
  • skinMix - микс цвета кожи

Человек — что сделать

  • Собеседование: отойти в сторону, войс на шёпот (P → 1). Только для самого первого персонажа.
  • Фото: поза «Важный», без очков/масок; пост в #Avenger-faces: «Имя Фамилия | ID».
  • Паспорт: имя, фамилия, возраст; при 18+ - * перед именем; после смены ника — написать что-то в /me.
  • Discord: #whitelist (30 мин, 1 использование), объяснить Information, Call‑admin, Wait‑me.
  • Инструктаж: Авенджер — последняя NON‑RP зона; парашют ЛКМ или F; без анимаций; не на территории группировок; перед приземлением - SHIFT; в ноке - тикет.
  • F11 — таблица биндов/анимаций; у человека есть бумажная карта (ESC).

Животные/обезьяны — что сделать

  • Фото: сидячая/уместная поза, без очков/масок; пост в #Avenger-faces: «Имя | ID».
  • Паспорт: фамилия «???» или 3 пробела (по правилам проекта).
  • Роли: выдать нужную — animal / capuchin / ape / orangutang / gorilla.
  • Карта: у животных карты нет; обезьянам — получить РП‑путём.
  • Нож/топор: не выдаём; у обезьян нож — РП‑добыча.

У животных забираем:

  • Парашют
  • Топор и нож
  • Спальник
  • Набор для розжига костра
  • НЭП
  • Сигнальный пистолет
  • Фильтр для воды

У обезьян забираем:

  • Парашют
  • Топор
  • Спальник
  • Набор для розжига костра
  • НЭП
  • Сигнальный пистолет
  • Фильтр для воды
Нож — РП‑добыча после выпуска.
